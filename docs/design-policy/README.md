# 設計ポリシー（Design Policies）

本ディレクトリでは、[エンジニアリング原則](../engineering-principles/README.md) を具体的な設計作業や繰り返し発生する設計判断に適用するための具体的なポリシーを定義します。

エンジニアリング原則が「所有権、不変条件、事実源、型、不変性」といった普遍的な思考の枠組みを規定するのに対し、設計ポリシーはそれらをデータソースの追加やデータ基盤の機能拡張といった特定の変更シナリオに適用し、実装前に参照すべきガイドラインを提供します。

## ポリシー一覧

* [現在の確実性のレベルで設計する (Design at the Current Level of Certainty)](design-at-current-certainty.md)  
  現時点で何が確定しており、何を意図して決定を保留すべきか（未確定のまま余白を残すべきか）を判断するための共有思考モデル。
* [データソースと機能の設計ポリシー (Datasource and Feature Design Policy)](datasource-and-feature.md)  
  新しいデータソース（Discord の新エンドポイントや外部プラットフォーム）の取り込み、データモデルの拡張、派生プロジェクションの設計時に遵守すべき具体的チェックリスト。
