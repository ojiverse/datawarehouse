# インフラストラクチャ設計

本ディレクトリでは、[アーキテクチャ設計](../architecture/README.md) において定義されたコンポーネント構成を、クラウド基盤上の具象リソースとして展開・運用するための詳細設計を定義する。

## 責務と対象領域

インフラストラクチャ設計は、特定のクラウドプロバイダに依存した具象設定を規定する階層である。以下の項目を包括的に定義する。

* **リソース構成（Resource Topology）**: クラウドサービスのインスタンス分割、サイジング、および名前空間
* **環境分離（Environments）**: 開発（Development）、検証（Beta）、本番（Production）の分離構成
* **バインディングと権限（Bindings & IAM）**: サービス間を接続するバインディング設定と最小権限の原則
* **セキュリティと秘匿情報（Security & Secrets）**: API トークン等の安全な注入と管理
* **デプロイと IaC（Deployment & IaC）**: 構成管理ツール（Wrangler, Terraform 等）と CI/CD パイプライン
* **コストとクォータ（Cost & Quotas）**: プラン選定、課金上限、およびリソース制限の管理

## 採用インフラ基盤

本システムの主基盤として **Cloudflare** を全面的に採用する。
Cloudflare 固有のリソース定義、設定値、および運用規則は、以下のエントリポイント配下で詳細化される。

* [cloudflare/](cloudflare/README.md): Cloudflare 上でのインフラストラクチャ詳細設計

※ 将来的にインフラ基盤の変更またはマルチクラウド展開を行う場合であっても、ドメイン設計およびアーキテクチャ設計を維持したまま、本インフラストラクチャ設計層のみを差し替え可能な構造を維持する。
