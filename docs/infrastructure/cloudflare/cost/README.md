# Cloudflare コストとキャパシティ設計

本ディレクトリでは、Discord DWH を Cloudflare 上で運用するにあたって発生するインフラストラクチャ費用、利用枠（Included Quota）、およびコスト最適化とデータ耐久性のトレードオフ原則を扱います。

## プラン選定と月額コスト試算（本番環境）

本番環境では、WebSocket 常時接続とバックグラウンドタスクの安定実行のため、**Workers Paid プラン（月額 $5〜）** を基本契約として採用します。

| リソース項目 | 料金体系（Workers Paid 基準） | 本システム（1シャード）での月間想定利用量 | 追加課金の見込み |
| :--- | :--- | :--- | :--- |
| **Workers 基本料金** | $5.00 / 月 | 基本プラン適用 | $5.00（固定） |
| **Workers リクエスト** | 1,000 万回までプランに含む | 約 200 万〜500 万リクエスト / 月 | 枠内に収まる見込み（$0） |
| **Durable Objects Duration** | 400,000 GB-s までプランに含む | 128MB × 86,400秒 × 30日 ≈ 324,000 GB-s | **枠内に収まる見込み（$0）** |
| **Durable Objects リクエスト** | 100 万回までプランに含む | WebSocket 接続確立 + 定期アラーム | 枠内に収まる見込み（$0） |
| **Cloudflare Queues** | 100 万回操作まで無料 | 約 100 万〜300 万操作 / 月 | $0.40 / 100万操作（数百円程度） |
| **R2 Storage** | 10 GB まで無料、超過分 $0.015 / GB | 数 GB〜数十 GB（年数に伴い増加） | 100GB でも月額 $1.50 程度 |
| **R2 Class A 操作（PUT）** | 100 万回まで無料、超過分 $4.50 / 100万回 | キューバッチ集約により月数万〜十万回 | **無料枠内に収まる見込み（$0）** |
| **R2 Class B 操作（GET）** | 1,000 万回まで無料 | 分析クエリ・リプレイ時のみ発生 | 無料枠内に収まる見込み（$0） |

※ 初期フェーズ（単一シャード・数ギルド規模）においては、**月額約 $5〜$10 前後の極めて低廉なランニングコスト**で安定運用が成立する見込みです。

## コストと耐久性に関する基本不変条件

* **耐久性の犠牲によるコスト削減の禁止**: コストを削減したいという理由だけで、Observation Archive の保存を省略したり、キューのバッチサイズを過剰に大きくしてメモリ内ロストのリスクを高めるような、システムのデータ耐久性・回復可能性を暗黙に弱める設計変更を禁じます。
* **トレードオフの明文化**: もしコスト上の強い要請によりデータ保証レベル（例: 生ログの保存期間短縮など）を変更する場合は、必ずアーキテクチャ設計および [ADR](../../../adr/README.md) にその判断とリスクを記録します。

## ベータ期間での実測検証項目

* Durable Objects の実測メモリフットプリント（128MB 以内に安定して収まっているか）
* キューのバッチサイズに応じた R2 Class A 操作数の実測値
* R2 SQL のデータ走査量（スキャン GB 数）とクエリ課金の実測
