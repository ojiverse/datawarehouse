# 開発姿勢と問題解決（Approach）

本ディレクトリでは、設計および実装の着手前段階において、エンジニアおよび AI エージェントが課題を分析し、優先順位を判断するための**開発姿勢と行動規範**を定義する。

## 原則一覧

* [成否を決定づける支配的要因を見極める (Find the Dominant)](find-the-dominant.md)  
  成果の価値を決定づけるのは努力量ではなくシステムの構造である。課題の成否を左右する支配的要因へリソースを集中させ、表面的な対症療法ではなく構造的要因を解消する。
* [正しさを判定する評価基準を最初に築く (Optimize Function First)](optimize-function-first.md)  
  実装コードの作成に先立ち、成果物の正当性を客観的に検証可能な評価基準（オラクルや検証データセット）を先行して確立する。
* [人間は舵取りに徹し、実装は機械に委ねる (Human Steers, AI Implements)](human-steers-ai-implements.md)  
  責務境界、契約、不変条件、安全網を厳格に制御し、個別のコード記述や文体への手動介入を排して全体最適を統制する。
